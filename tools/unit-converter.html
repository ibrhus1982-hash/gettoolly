What Is a Unit Converter?

A unit converter is a tool that changes a measurement from one unit to another. Unit conversion is useful in everyday life, education, science, engineering, cooking, travel and many other situations.

Units Supported by This Converter

GetToolly's converter currently supports common length, weight, temperature and volume units.

Length: meters, kilometers, centimeters, millimeters, miles, yards, feet and inches.

Weight: kilograms, grams, milligrams, pounds and ounces.

Temperature: Celsius, Fahrenheit and Kelvin.

Volume: liters, milliliters, gallons, quarts, pints and cups.

How to Use the Unit Converter

First select the type of measurement you want to convert. Enter a value, choose the original unit and then select the unit you want to convert to.

The result is calculated automatically as you change the value or units.
