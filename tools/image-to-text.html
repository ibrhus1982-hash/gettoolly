Image to Text Converter

GetToolly Image to Text Converter allows you to extract editable text from JPG, PNG and WebP images using Optical Character Recognition (OCR).

How to Extract Text from an Image

Upload an image, choose English or Arabic, then click Extract Text. The recognized text will appear below the image.

Arabic OCR

Arabic OCR is supported for printed Arabic text. For mixed Arabic and English images, GetToolly processes the two languages separately to improve recognition.

What is OCR?

OCR stands for Optical Character Recognition. It converts text contained inside an image into editable digital text.
