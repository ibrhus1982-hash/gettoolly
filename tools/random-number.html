What Is a Random Number Generator?

A random number generator creates numbers selected from a specified range. It can be useful for games, drawings, testing, simulations, classroom activities and everyday decisions.

How to Use the Random Number Generator

Enter the minimum and maximum values you want to use. Choose how many numbers you want and click "Generate Random Number."

If duplicate numbers are not allowed, each generated number will be unique within the requested range.

Random Number Example

Minimum: 1

Maximum: 100

The tool can generate five random integers between 1 and 100.

What Does "Allow Duplicates" Mean?

When duplicates are allowed, the same number can appear more than once in the generated results.

When duplicates are disabled, every generated number must be different from the others.

Common Uses for Random Numbers

Random numbers can be used for selecting winners, creating game numbers, generating test data, choosing classroom activities and making simple random selections.
