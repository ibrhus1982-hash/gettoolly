What Is a Password Generator?

A password generator creates random combinations of letters, numbers and symbols that can be used as passwords for online accounts and services.

Strong, unique passwords can make it harder for attackers to guess or reuse your credentials.

How to Create a Strong Password

For better security, use a longer password and include a mixture of uppercase letters, lowercase letters, numbers and symbols when the website you are using allows them.

Avoid using easily guessed information such as names, birthdays, phone numbers or common words.

Recommended Password Length

Longer passwords generally provide more possible combinations than shorter passwords. A password length of 16 characters or more is a useful starting point for many accounts.
