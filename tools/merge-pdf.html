About Merge PDF

GetToolly's Merge PDF tool allows you to combine multiple PDF files into one PDF document quickly and easily.

You can select two or more PDF files and combine them into a single document without installing additional software.

How to Merge PDF Files

Select two or more PDF files using the upload area above. Your selected files will appear in the list.

The files are merged in the same order shown in the list. Click "Merge PDF Files" to create your combined document.

When the process is complete, click "Download Merged PDF" to save the new PDF file.
