What Is a QR Code?

A QR code is a type of two-dimensional barcode that can store information such as website URLs, text, contact details and other data.

QR codes can be scanned using most modern smartphones without installing a special application.

How to Create a QR Code

Enter your text or website URL in the box above, choose the desired size and click Generate QR Code. You can then download the generated QR code as a PNG image.

What Can You Use a QR Code For?

QR codes can be used for websites, online menus, business information, contact details, social media profiles, Wi-Fi information, digital invitations and many other purposes.

Does the QR code expire?

A QR code generated from information stored directly in the code does not normally expire. However, if it contains a website URL, the QR code will only work while that URL remains available.
